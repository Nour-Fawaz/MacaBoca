# Project Name

Developer Names: Nour Fawaz, Yilin Jiang, Javayria Mudassar, Catherine Yang

Date of project start: 09-16-2026

TeLaC is a web-based, clinician-facing telehealth platform that streamlines how speech-language pathologists review, annotate, and track bilingual (Mandarin-English) pediatric speech assessments.

The folders and files for this project are as follows:

docs - Documentation relevant to the project
refs - Reference material used for the project, including papers
src - Source code
test - Test cases
