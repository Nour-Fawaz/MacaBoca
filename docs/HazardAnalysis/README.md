# Hazard Analysis

This folder contains the hazard analysis for TeLaC. It identifies potential hazards in the system, assesses their risks, and defines the safety requirements and mitigations that address them.

The folders and files for this folder are as follows:

- `HazardAnalysis.tex`: LaTeX source for the hazard analysis.
- The compiled PDF version can be viewed in the file `HazardAnalysis.pdf`
