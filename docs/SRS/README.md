# Software Requirements Specification (SRS)

This folder contains the Software Requirements Specification for TeLaC. It defines the purpose and scope of the system, its users and stakeholders, and its functional, non-functional, data, and AI/ML requirements.

<The SRS is for a single product, not a family of products. A Commonality Analysis is
more appropriate for a family of products.>

<The template in this folder is suited to Scientific Computing (also known as 
Research Software) projects>

The folders and files for this folder are as follows:

- `SRS.tex`: LaTeX source for the SRS.
- The compiled PDF version can be viewed in the file `SRS.pdf`.
