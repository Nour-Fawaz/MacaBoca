# Verification and Validation Plan

This folder contains the Verification and Validation Plan for TeLaC. It describes how the team will verify that the software is built correctly and validate that it meets the requirements in the SRS, including the planned tests and evaluation methods.

The folders and files for this folder are as follows:

- `VnVPlan.tex`: LaTeX source for the VnV plan.
- The compiled PDF version can be viewed in the file `VnVPlan.pdf`.
